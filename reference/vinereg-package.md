# vinereg: D-vine regression models

Fit D-vine copula regression models for conditional mean and quantile
prediction with continuous or discrete variables. The package provides
automatic covariate selection, fixed-order models, conditional
distribution diagnostics, and marginal fitted-quantile plots.
